# Delposh Beauty & Fitness — website starter

This is a responsive, mobile-first one-page website for Delposh Beauty & Fitness, built around the supplied Delposh logo and the verified public listing details available during the research pass.

## Verified business details used
- Address: 68 Ago Palace Way, bus stop, Lagos 100263, Nigeria
- Phone: +234 803 833 1521
- Public listing rating: 4.4/5 from 16 reviews
- Listed hours: Mon–Sat 06:30–21:00; Sun 13:00–20:00
- Spa Instagram: https://www.instagram.com/delposhspa/
- Fitness Instagram: https://www.instagram.com/delposhfitness/

The exact Instagram profile pages were not fetchable by the research environment because Instagram throttled automated page access. For that reason, the site does **not** misrepresent stock imagery as Delposh-owned media. The gallery and hero currently use curated visual placeholders, while the live Delposh Instagram accounts are directly linked throughout the site.

## Before launch
1. Replace the placeholder Web3Forms key in `index.html`:
   `YOUR_WEB3FORMS_ACCESS_KEY_HERE`
2. Replace the curated media URLs with Delposh-approved social images/video once the owner has provided or exported the relevant media.
3. Review the service wording against Delposh's current service menu before publishing. The wording intentionally avoids inventing specific treatments/programs that could not be verified from the available public sources.

## Files
- `index.html` — page structure, content, Web3Forms form
- `styles.css` — responsive styling, theme system, layout and animation CSS
- `script.js` — light/dark mode, mobile navigation, Web3Forms submission, GSAP motion
- `assets/logo-transparent.png` — transparent version of the supplied logo
- `assets/logo-dark.png` — dark-theme visibility version of the supplied logo

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server.

No build step is required.
